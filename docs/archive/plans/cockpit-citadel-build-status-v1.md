# cockpit-citadel-build-status-v1

The finished citadel level stays at L0 until the build's completion day. The planet row, the sector planet line, and the stage hint were naming that finished level, so an L1 build read as L0.

The cockpit now says "citadel L1 building, done day N" from the target and the completion day already on the observation. An owned planet with no build still says "no citadel started" on the stage line. No engine switch, and the prompt text is unchanged.
