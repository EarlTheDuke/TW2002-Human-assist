# planet-dividend-fidelity-v1

The original does not pay a credit dividend when a planet's value rises. This game does: 30 percent of the new value. That payment stays on, because the recorded games already include it. `PLANET_DIVIDEND_PAY_MODE` `off` pays nothing, and the baseline still moves so a later day does not pay the missed gain in one lump.

The planet panel says "30% of new value" or "none". It also says colonists grow about 5 percent while organics last. When the live production rule is on and the planet is above half its class cap, the panel says about 5 percent die off each day.
