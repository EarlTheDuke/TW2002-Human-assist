# avoid-list-v1

`AVOID_MODE` stays `legacy`.

Off, the computer has no avoid list. A plotted course may pass through any sector, and a death does not record one.

On, naming a sector adds it. Naming 0 clears the list. A death adds the sector where the ship was lost. A plotted course goes around the list. When the list is not empty, the view says so and says that 0 clears it.

death-pod-v1 left this out because the ship had no list to write to. This switch is that list.
