# radio-channels-v1

`RADIO_CHANNEL_MODE` stays `legacy`.

Off, corp chat is still the one memo. The radio action is refused, and the legal list does not offer it. A player dump leaves the channel out while it is unset.

On, a corp member tunes a subspace channel from 0 to 60000. That range is the Bible's. A message goes only to corp mates tuned to the same channel. Someone outside the corp cannot tune it.

The live profile stays off. This switch is added to that profile at the Batch N gate.
