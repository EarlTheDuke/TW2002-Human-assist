# planet-value-cap-v1

PLANET_VALUE_SCORE_MODE stays legacy, so recorded games still rank on the credit score. The growth dividend still uses that same planet value.

The other settings are options:

- `stock_cap` counts planet stock only up to the handbook maximum for that class.
- `no_fighters` leaves planet fighters out of the score.
- `colonists` scores the planet as its colonists alone.
- `experience` ranks the day-cap winner by experience. The original does this. The live profile uses this one.

The free starting planet is already a class M with 191,000 colonists, empty stock, and no fighters. That was starting-package-v1. This slice does not change it.
