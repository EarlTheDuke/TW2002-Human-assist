# TW2002 reference

The game we copy is Trade Wars 2002 version 3, the way TWGS 3.11 ran it. When a TWGS write-up and an MBBS write-up name the same number, use the MBBS number. When they disagree, write the conflict down and keep our choice as a constant.

We do not have the official manual or the game source.

These files are community pages and in-game help text saved on 2026-10-03. Nothing here is bigger than 3 MB. No zip and no program file was in the folder.

Not copied, on purpose:

- `github_selected_files/rdearman__twclone/` C files (`repo_citadel.c`, `repo_combat.c`, `repo_port_rules.c`). Those are program source, and the library notes say that project is not an exact copy.
- `github_selected_files/TW2002__mombot/` script files (`.ts`) and `TW2002__twxp/` sample `.cfg` files. Those are helper code and a sample config, not a rules page.
- Two `LICENSE` files with no name ending. They are license text, not a rules page.
- No file in the folder was over 3 MB, and there was no zip or exe to skip.
- There is no `S5` file.
