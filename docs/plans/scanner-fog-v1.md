# scanner-fog-v1

`SCANNER_FOG_MODE` stays `legacy`.

Off, a sector list still names a planet's owner. The owner still sees that planet's fighters without landing.

On, owner, fighters, and shields stay off that list. Landing on the planet shows all three. A planet scanner, which stays behind its own switch, shows the owner and the fighters when the planet has no shields. It does not show shields. A shielded planet stays dark from space.

The live profile stays off. This switch is added to that profile at the Batch N gate.
