# cockpit-buy-list-affordability-v1

A ship you cannot buy stays on the yard list, greyed, with the reason the server already sent (credits, alignment, corporation, or already owned). Gear you cannot buy stays on the dock list with "not enough credits" or "no room on the ship".

Typing more than the order allows no longer just rewrites the box. The preview says it was cut, for example from 270 to 269. No engine switch.
