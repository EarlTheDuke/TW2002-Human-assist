# async-days-v1

`ASYNC_DAY_MODE` stays `legacy`.

Off, seats still take turns one at a time. A day ends only when every seat is out of turns.

On, every seat that can still move answers in the same pass. The answers are applied in seat order, so a code-only game repeats. The day also ends when 20 minutes have passed, even if turns are left. A seat that does not answer in time waits.
