# cockpit-redesign-screens-v1

I opens a ship screen: hull, commander, class, holds, fighters, shields, the warp turn cost, and the gear already on the ship. The log is one list, newest at the top, using the sentence the server already wrote. A landed planet shows its citadel level and quasar percents. A quasar or build form repeats those numbers and uses a percent slider when the command asks for one.
