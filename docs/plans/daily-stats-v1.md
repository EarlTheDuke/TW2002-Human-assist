# daily-stats-v1

`DAILY_STATS_MODE` stays `legacy`.

Off, a seat's view does not carry the V-screen counts.

On, the view counts ports, planets, traders, aliens, and fighters and mines in use. A live game showed the port count and a line for fighters and mines in use. This count includes fighters and mines on ships, in sectors, and on planets. Whether the original screen counts cargo the same way as a deployed stack is not confirmed.

The live profile stays off. This switch is added to that profile at the Batch N gate.
