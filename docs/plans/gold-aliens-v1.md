# gold-aliens-v1

`GOLD_ALIEN_MODE` stays `legacy`.

Off, destroying an alien does not start a grudge.

On, if another alien of the same race is in the sector, the killer goes to the top of that race's list. The list holds ten names. A kill with no witness does not start one. The list is not saved, so a reload clears it. How much harder a grudge hits is not published, so the fight does not change. Banding has no published group size, so clusters are not invented. Protective return fire uses the alien's own ship, and that second pass is not in this slice.

The live profile stays off. This switch is added to that profile at the Batch N gate.
