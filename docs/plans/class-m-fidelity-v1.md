# class-m-fidelity-v1

`CLASS_M_FIDELITY_MODE` stays `legacy`.

Off, a class M level 1 still asks for 1,000 colonists, the handbook unit.

On, that level asks for 1,000,000 people. 999,000 is refused. 1,000,000 with 300 fuel ore, 200 organics, and 250 equipment is allowed, and the build takes 4 days. Other classes are not multiplied. Class L level 1 stays the S1 figure of 400 handbook thousands (400,000 people). The materials and the day counts were already in the class table. Each product pool holds 30,000 thousand. A pool under that line does not shrink. Only the extra above it loses about 5 percent a day, and that rate is not a published number. The screen says the count and how many thousands that is.

Fuel fighters were already one per 30 colonists. Product storage was already 100,000. The live profile stays off. This switch is on that profile list.
