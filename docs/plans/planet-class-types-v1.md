# planet-class-types-v1

`PLANET_CLASS_MODE` stays `legacy`.

Class U level 1 is already 3,000 colonists, 1,200 ore, 400 organics, 2,500 equipment, and 8 raw days, with no credit cost. Class M level 1 is already 300 ore, 200 organics, 250 equipment, and 4 raw days. The class M colonist count stays 1,000. The 1,000 versus 1,000,000 question is still open. Product caps are already 100,000 on M and 10,000 on U. Experience for a launch is already 25. A scout already holds no torpedo.

On, a new planet is only class M or class U, using the weights those two already had. The launch costs no turn and 10 alignment. A freighter holds one torpedo. The torpedo costs 20,000. The citadel hint prints the fuel, organics, and equipment the server already sends, instead of a credit line, when those goods are present.
