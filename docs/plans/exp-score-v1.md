# exp-score-v1

2026-10-11. `EXP_SCORE_MODE` stays `legacy`.

The tw2002 experience table is already in the game. A successful trade is 1. The first trade at a port is 1. A new planet is 25. Destroying a port is 50. A warp is 0 on that table.

Live ranks the status line and the end table by experience. Net worth stays on the row. A warp gives 0 even on the old experience table. The match still ends on net worth.
