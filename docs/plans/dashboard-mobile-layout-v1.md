# dashboard-mobile-layout-v1

At 390 pixels the map and the event feed had no height, the page could not scroll, and the header ran off the right edge.

Below 720 pixels the page stacks the map, the feed, and the seats, and the page scrolls. The header wraps onto its own rows. A 1440 or 1920 screen stays side by side. The resize handles are hidden on the phone so they do not pin the old widths.
