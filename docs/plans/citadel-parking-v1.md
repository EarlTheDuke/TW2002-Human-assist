# citadel-parking-v1

`CITADEL_PARK_MODE` stays `legacy`.

Off, landing on a citadel leaves the ship in the sector. A parked-ship record has no planet, and a Fed tow still runs.

On, a ship landed on your own level-1 citadel is inside it. Another trader cannot attack it there. A Fed tow skips it, including the overnight crowding tow. A hull you leave there remembers that citadel and can be boarded again only while you are landed on it.

The corporation rule that already refuses a ship you cannot board is unchanged. The live profile stays off. This switch is added to that profile at the Batch N gate.
