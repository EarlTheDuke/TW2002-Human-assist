# cockpit-scene-image-v1

The window above the map stays 16:9. It shows one still chosen from the fogged observation: deep space, a port, StarDock, Terra, FedSpace, your planet, someone else's planet, or the escape pod. The name comes from the scene keys. A missing file uses the next key, then the drawn stars, so the box is never a broken image.

The pictures used here are the webp copies. Each is under 300 KB. The larger png copies stay on disk for the older still list. The page loads only the one picture it is showing, from this same site. visuals=0 leaves the window on the drawn stars.
