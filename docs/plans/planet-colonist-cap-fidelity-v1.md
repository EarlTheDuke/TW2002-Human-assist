# planet-colonist-cap-fidelity-v1

Game 5 stopped a level 2 planet at 3,000 colonists. Level 3 on that class asks for 5,000, so the quasar (a level 3 feature) could not be built.

The handbook, the Gypsy guide, the modern manual, and the softdocs table all say a class U planet holds 3,000 colonists. Class M holds 30,000 in those same four sources. The million-colonist figure is the unsettled citadel level-1 screen, not this population cap. SOURCE-CONFLICT: this slice does not change class M.

`PLANET_COLONIST_CAP_MODE` stays `legacy`, so the handbook numbers and the bank pin stay. `live` raises a class only when the handbook cap is below the most colonists any citadel level on that class asks for. Class U becomes 8,000 (level 5). Every other class already clears its own citadel ask, so those numbers do not move.
