# alignment-v1

2026-10-11. `ALIGNMENT_MODE` stays `legacy`.

Lost fighters already move alignment by the fighters you lost times the other trader's alignment, divided by 5,000, toward zero. 10,000 fighters lost against alignment -100,000 is +200,000. A trader with alignment of 0 or more and 999 experience or less is already safe from attack in FedSpace. A negative alignment is not.

Live names those same rules. A posted reward is already +1 alignment per 1,000 credits. There is no colonist-jettison verb, so that penalty is not added. Turning the switch on does not change a game.
