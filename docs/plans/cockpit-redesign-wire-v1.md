# cockpit-redesign-wire-v1

`COCKPIT_LAYOUT` stays off. `/bot` is the old page. `?layout=redesign` or `COCKPIT_LAYOUT=redesign` serves the winning helm, and `/bot2` serves that same page.

It reads the seat observation and posts actions the same way the old page does. Scene stills and clips come from the existing media player. StarDock gear, shipyards, and the bank open from button listeners, not from an inline `form` call.
