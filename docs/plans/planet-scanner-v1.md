# planet-scanner-v1

`PLANET_SCANNER_MODE` stays `legacy`.

Off, StarDock does not sell a planet scanner. A stranger still cannot read a planet's fighters. A ship dump leaves the new field out while it is false.

On, StarDock sells one planet scanner for 30,000 credits. That is the price on the live Trade Wars server. The scanner shows the fighters of a planet that has no shields. A planet with shields stays dark. A second scanner does not fit.

The live profile stays off. This switch is added to that profile at the Batch N gate.
