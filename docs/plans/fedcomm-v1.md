# fedcomm-v1

`FEDCOMM_MODE` stays `legacy`.

Off, Extern still clears fighters on a major space lane and keeps the old sweep note. The owner gets no Federation message.

On, the owner also gets "Don't deploy fighters in the MSL's." and the sector number. That line is the handbook message for fighters the feds pick up on a lane. A mine-only sweep does not invent a second line.

The live profile stays off. This switch is added to that profile at the Batch N gate.
