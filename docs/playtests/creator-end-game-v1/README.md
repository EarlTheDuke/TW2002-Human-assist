# creator-end-game-v1

The person who created a running game can end it. The lobby asks "End Alpha for everyone?" and then lists the game under Finished. In the redesign cockpit the creator's own seat gets "End game for everyone" on the game menu; another seat does not. After the end, the game-over panel reads "Ended by the game's creator." and shows the rankings.

- 1280-lobby-end.png and 390-lobby-end.png: End game on the creator's running game
- 1280-lobby-finished.png and 390-lobby-finished.png: Alpha on the finished list, gone from the open games
- 1280-menu-end.png and 390-menu-end.png: End game for everyone on the creator's menu
- 390-menu-hidden.png: the same menu for a seat that did not create the game
- 1280-game-over.png and 390-game-over.png: the creator line and the final rankings
