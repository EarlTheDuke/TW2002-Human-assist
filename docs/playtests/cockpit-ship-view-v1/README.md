# cockpit-ship-view-v1

Redesign cockpit (`?layout=redesign`). The ship panel keeps the same stat lines and adds the hull in space, with one red triangle per fighter up to 200. Two thousand fighters are 200 triangles and the line "each triangle = 10 fighters". The Escape Pod is the lifeboat with no fighters aboard.
